# 릴리스 노트

패키지: `com.tnkfactory.ad:hrwd` · 설치 방법은 [1. 설치](install.md)를 참고하세요.

과거 버전의 권장 사항은 당시 기준입니다. 현재 사용법은 각 기능 페이지를 따라 주세요.

---

## 1.0.16 — 2026-10-28

- 적립 가능 포인트 합계를 한 번에 받는 `getTotalPoint` 를 추가했습니다. 기존 네이티브 SDK `getEarnPoint` 를 이 함수 하나로 바꿀 수 있습니다. 기존 두 함수(`getAdvertiseTotalPoint` · `getProductTotalPoint`)는 그대로 쓸 수 있습니다 — [9. 적립 가능 포인트 조회](total-point.md)

## 1.0.15 — 2026-10-20

- 광고 참여 시 광고 추적이 제한된 기기에서 오퍼월이 띄우는 안내 팝업의 [설정으로 이동] 버튼이 기기의 광고 ID 설정 화면(예: 설정 > 개인정보 보호 > 광고, 기기마다 경로가 다를 수 있음)을 바로 열도록 개선했습니다. 이전에는 시스템 설정 첫 화면이 열렸습니다. 해당 화면을 열 수 없는 기기에서는 다른 광고 설정 화면 또는 시스템 설정 첫 화면이 열립니다. 연동 코드 변경은 필요 없습니다 — [문제 해결](troubleshooting.md)의 '추적 허용이 필요해요' 항목

**오퍼월 업데이트 (SDK 버전과 무관)**

- 위 안내 팝업에 설정 경로 안내 문구(`[설정] -> [개인정보 보호] -> [광고] -> [새 광고ID 받기]`)를 추가했습니다. 기기에 따라 메뉴 이름이 다를 수 있습니다. 앱 업데이트 없이 적용됩니다.

## 1.0.14 — 2026-10-19

- 개인정보 동의 철회 API `TnkPpiHybSdk.revokePrivacyConsent(context)` 를 추가했습니다. 앱의 "동의 철회" 동작에서 호출하면 동의가 즉시 해제되고, 열려 있는 오퍼월은 첫 화면부터 다시 열려 동의 팝업을 보여 줍니다. 이후 오퍼월 진입도 동의 팝업부터 시작합니다. 사용자의 철회 동작에서만 호출하세요 — [7. 개인정보 설정](privacy.md)의 '동의 철회' 항목

## 1.0.13 — 2026-10-07

- 다크모드에서 전체 화면으로 연 오퍼월(`openOfferwall`)의 하단 내비게이션 바 영역(제스처 내비게이션은 흰 줄, 3버튼 내비게이션은 밝은 회색)과 가로 화면에서 옆으로 오는 내비게이션 바 영역이 밝게 남던 문제를 수정했습니다. 해당 영역은 오퍼월 배경색으로 표시되고 내비게이션 바 아이콘 명암도 화면 테마에 맞춰집니다. 라이트모드는 이전과 같으며 연동 코드 변경은 필요 없습니다 — [4. 오퍼월 띄우기](offerwall.md)
- 오퍼월이 열리는 순간 다크모드에서 흰 화면이 잠깐 보이던 현상을 개선했습니다 — [4. 오퍼월 띄우기](offerwall.md)
- 화면 안에 삽입(`TnkOfferwallView`)한 경우에는 SDK 가 앱 창의 상태 바·내비게이션 바 배경색을 바꾸지 않으므로, 해당 영역은 앱 화면에 설정된 색 그대로 보입니다. 다크모드에서 어색하면 앱 화면 쪽 색을 맞춰 주세요 — [4. 오퍼월 띄우기](offerwall.md)의 '앱 화면 안에 넣기(삽입)' 항목

## 1.0.12 — 2026-10-06

- SDK 1.0.10 이하와 기존 네이티브 SDK(`com.tnkfactory:rwd`)에서 저장된 동의는 동의로 유지되며, 오퍼월의 "개인 정보 수집 동의 해제" 메뉴로 철회할 수 있습니다 — [7. 개인정보 설정](privacy.md)
- 앱을 재설치하거나 데이터를 복원한 뒤에도, 오퍼월의 동의 팝업 표시 여부가 앱의 동의 상태(`isAgreePrivacy`)와 일치하도록 개선했습니다 — [7. 개인정보 설정](privacy.md)
- `setAgreePrivacy(context, true)` 로 설정한 경우에만 오퍼월의 동의 팝업과 "동의 해제" 메뉴가 노출되지 않습니다. 이 버전에서는 앱 시작 시마다 `setUserName` 다음에 호출하도록 안내했습니다. **현재 기준:** 앱에서 동의를 직접 받은 사용자에게만 `true` 로 설정하세요. 동의를 철회한 사용자에게 다시 `true` 로 설정하면 철회가 취소됩니다(SDK 1.0.14 이상) — [7. 개인정보 설정](privacy.md)의 '동의 철회' 항목

## 1.0.11 — 2026-10-01

- 오퍼월에서 사용자가 동의·거부한 결과가 SDK 에 저장되어 `isAgreePrivacy(context)` 에 반영됩니다 — [7. 개인정보 설정](privacy.md)
- `setUserName` 으로 사용자가 바뀌면(최초 지정 포함) 동의 상태가 초기화됩니다. `setUserName` → `setAgreePrivacy` 순서로 호출하세요 — [7. 개인정보 설정](privacy.md)

**오퍼월 업데이트 (SDK 버전과 무관)**

- 특정 광고 진입(adDetail/adJoin/adAction)도 개인정보 동의 확인 후 진행됩니다 — [8. 특정 광고 진입](ad-entry.md)

## 1.0.10 — 2026-09-09

1.0.6 이후 1.0.10 까지의 변경 사항을 함께 정리한 항목입니다.

- Android 에뮬레이터·가상 기기에서는 오퍼월이 열리지 않습니다. 전체 화면으로 연 오퍼월은 아무 화면도 뜨지 않고, 화면 안에 삽입한 오퍼월은 빈 화면으로 남습니다. 동작 확인은 실기기에서 해 주세요 — [문제 해결](troubleshooting.md)
- 적립 가능 포인트 조회 API `getAdvertiseTotalPoint` / `getProductTotalPoint` 를 추가했습니다. 오퍼월을 열지 않고 적립 가능한 포인트 합계를 받아 앱 화면(배너·버튼 등)에 표시할 수 있습니다 — [9. 적립 가능 포인트 조회](total-point.md)
- 특정 광고 바로 진입 API `adDetail` / `adJoin` / `adAction` 을 추가했습니다 — [8. 특정 광고 진입](ad-entry.md)

## 1.0.6 — 2026-08-24

공개 가이드 최초 제공 기준 버전입니다.

- 전체 화면 오퍼월(`openOfferwall`) 및 화면 안에 삽입(`TnkOfferwallView`)
- 보상 지급 완료 알림(`setRewardListener`) · 범용 이벤트 수신(`setEventListener`)
- `tnkscheme://` 딥링크(`handleScheme`)
- 개인정보 동의 · COPPA · GDPR 설정
- 기존 네이티브 SDK(`com.tnkfactory:rwd`)의 `TnkSession` 과 같은 이름의 메서드를 `TnkPpiHybSdk` 로 제공 — [네이티브 SDK 에서 이관](migration.md)
